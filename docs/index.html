Ce que le connecteur importe

Finary fournit les positions. Gloom les affiche dans ses portefeuilles, avec les cours disponibles lorsque le titre est reconnu.

Investissements

Les positions et leur prix de revient, lorsque Finary le fournit. Les titres peuvent être rapprochés de leur symbole de marché.

Cryptos

Les quantités et les valorisations remontées par Finary, regroupées par compte.

Actifs manuels

Les actifs que vous avez saisis dans Finary, regroupés par devise dans Gloom.

Première synchronisation

Gloom 0.20.20 ou plus récent est recommandé. Le connecteur utilise Python 3.10+ et une session locale finary_uapi.

Version v1.0.6

  1. Télécharger Gloom

    Ouvrez l’application de bureau ou utilisez le terminal. Gloom Pro est facultatif pour l’import. · Lien affilié

  2. Installer le connecteur

    Exécutez cette commande dans votre terminal, puis relancez Gloom.

    gloom install lbonvarl/gloomberb-finary-downloads
    Télécharger le ZIP
    Installation manuelle avec le ZIP

    Décompressez le dossier gloomberb-finary dans le dossier plugins de Gloom, puis relancez l’application. La commande gloom plugins indique l’emplacement utilisé sur votre système.

  3. Installer finary_uapi et se connecter à Finary

    Dans ce terminal, créez un dossier de session local et installez le paquet finary_uapi sur PyPI. Si vous avez déjà une session active, passez à l’étape suivante avec le Python et le dossier de cette session.

    macOS ou Linux

    install -d -m 700 "$HOME/.config/finary_uapi"
cd "$HOME/.config/finary_uapi"
umask 077
python3 -m venv .venv
.venv/bin/python -m pip install finary_uapi

    Dans ce dossier, créez credentials.json à partir du modèle de configuration. Renseignez votre e-mail et votre mot de passe Finary dans ce fichier local, puis lancez la connexion depuis le même dossier.

    .venv/bin/python -m finary_uapi signin

    Consultez le guide de démarrage de finary_uapi pour les détails de connexion. Gardez le fichier d’identifiants et les fichiers de session dans votre dossier privé.

    Commandes pour Windows (PowerShell) 
    $session = Join-Path $env:LOCALAPPDATA "finary_uapi"
New-Item -ItemType Directory -Force -Path $session
Set-Location $session
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install finary_uapi

    Créez credentials.json dans ce dossier comme indiqué ci-dessus, puis lancez la connexion.

    .\.venv\Scripts\python.exe -m finary_uapi signin

  4. Configurer le profil Finary et synchroniser

    Dans Gloom, ajoutez un profil Finary depuis le panneau Brokers (BR).

    Dans Python executable, indiquez le chemin absolu du Python utilisé pour la connexion (.venv/bin/python sur macOS ou Linux, .venv\Scripts\python.exe sous Windows). Dans finary_uapi data directory, indiquez le chemin absolu du dossier depuis lequel vous avez lancé signin.

    Enregistrez le profil, puis lancez Sync.

Vos données et vos choix

La connexion modifie-t-elle mon compte Finary ?

L’import se fait en lecture seule. La connexion et son renouvellement sont gérés localement par finary_uapi.

Quelles données sont envoyées à Yahoo Finance ?

Si la recherche Yahoo Finance est activée, l’ISIN et le libellé des titres éligibles sont utilisés pour identifier les symboles. Désactivez Search Yahoo Finance dans le profil pour conserver la résolution des titres en local.

Puis-je garder le portefeuille sur cet appareil ?

Dans Gloom, sélectionnez Keep on this device pour les données de compte si vous souhaitez les conserver uniquement sur cet appareil.
