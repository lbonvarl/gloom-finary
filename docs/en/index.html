What the connector imports

Finary supplies the positions. Gloom displays them in your portfolios, alongside market prices when the security can be identified.

Investments

Positions and cost basis where Finary provides them. Eligible securities can be matched to market symbols.

Crypto

Quantities and values reported by Finary, grouped by account.

Manual assets

Assets you entered in Finary, grouped by currency in Gloom.

Run your first sync

Gloom 0.20.20 or newer is recommended. The connector uses Python 3.10+ and a local finary_uapi session.

Version v1.0.6

  1. Download Gloom

    Open the desktop app or use the terminal. Gloom Pro is optional for imports. · Affiliate link

  2. Install the connector

    Run this command in your terminal, then restart Gloom.

    gloom install lbonvarl/gloom-finary
    Download the ZIP
    Install the ZIP manually

    Extract the gloomberb-finary folder into your Gloom plugins directory, then restart the app. The gloom plugins command shows the location on your system.

  3. Install finary_uapi and sign in to Finary

    In your terminal, create a local session folder and install finary_uapi from PyPI. If you already have an active session, go to the next step with the Python executable and folder you used for that session.

    macOS or Linux

    install -d -m 700 "$HOME/.config/finary_uapi"
cd "$HOME/.config/finary_uapi"
umask 077
python3 -m venv .venv
.venv/bin/python -m pip install finary_uapi

    In that folder, create credentials.json from the configuration template. Add your Finary email and password to that local file, then sign in from the same folder.

    .venv/bin/python -m finary_uapi signin

    See the finary_uapi quick start for sign-in details. Keep the credentials file and session files in your private folder.

    Commands for Windows (PowerShell) 
    $session = Join-Path $env:LOCALAPPDATA "finary_uapi"
New-Item -ItemType Directory -Force -Path $session
Set-Location $session
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install finary_uapi

    Create credentials.json in that folder as described above, then sign in.

    .\.venv\Scripts\python.exe -m finary_uapi signin

  4. Set up the Finary profile and sync

    In Gloom, add a Finary profile from the Brokers panel (BR).

    For Python executable, enter the absolute path to the Python executable you used to sign in (.venv/bin/python on macOS or Linux, .venv\Scripts\python.exe on Windows). For finary_uapi data directory, enter the absolute path to the folder where you ran signin.

    Save the profile, then select Sync.

Your data and your choices

Does the connector change anything in my Finary account?

Imports are read-only. finary_uapi handles sign-in and session refresh locally.

What does Yahoo Finance receive?

When Yahoo Finance lookup is enabled, eligible holdings are searched using their ISIN and display name. Turn off Search Yahoo Finance in the profile to keep symbol resolution local.

Can I keep my portfolio on this device?

In Gloom, select Keep on this device for account data if you want to store the imported portfolio locally.
