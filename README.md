# Finary for Gloom

Independent, read-only Finary portfolio connector for Gloom. This distribution
repository contains the compiled plugin and the bilingual project site.

[Français](https://lbonvarl.github.io/gloom-finary/) ·
[English](https://lbonvarl.github.io/gloom-finary/en/)

```sh
gloom install lbonvarl/gloom-finary
```

Gloom 0.20.20 or newer is recommended. The connector requires Python 3.10+
and an active local [finary_uapi](https://github.com/lasconic/finary_uapi)
session. The site covers setup, manual installation, and data handling.
